# ミラーイメージ研究室の3D化

## 要求と実装

- 四腔・大血管・冠動脈を備えた既存の独自WebGLメッシュをミラーイメージ研究室へ接続。
- スライダー、仮想視点、波形補間、旧平面図と専用CSSを削除。
- 標準12誘導とV7〜V9の選択。選択は青、鏡像側は橙のボタンで表示し、文字でも区別。
- 下壁群とⅠ・aVL、後壁追加誘導群とV1〜V3を双方向に選択可能。aVR・V4〜V6に固定ペアを捏造しない。
- 下壁場面は左室下壁、後壁場面は左室後壁側を強調。選択がST低下側でも、この代表場面のST上昇側心筋を示すことを明記。
- 四腔名・主要冠動脈名・大血管名を切り替え。冠動脈はLMT/LAD/LCx/RCA/PDAに加え対角枝・鈍縁枝・右縁枝を描画。
- 座標は患者の左が+X、頭側が+Y、前が+Z。右優位型の模式形状。領域と血管強調は患者固有の灌流域・責任血管の確定ではない。

## 照合資料

- https://pmc.ncbi.nlm.nih.gov/articles/PMC8200569/ 冠動脈の正常走行・分岐と優位性。
- https://pmc.ncbi.nlm.nih.gov/articles/PMC1291319/ 下壁と高位側壁、前胸部と背部の鏡像関係。
- https://pmc.ncbi.nlm.nih.gov/articles/PMC8762803/ 後壁の追加誘導と前胸部ST低下。

- 自動テスト68件成功。全15誘導の対応と逆方向選択、固定対応なしの誘導を検証。

- localhost:3000/labs/mirrorで実際のWebGL描画を確認。下壁の下方視点、後壁の背面視点と冠動脈、正面の大血管ラベルを目視確認。
- 全15ボタンをブラウザでクリックし、選択、鏡像側、強調領域が一致。range入力0。

## 追加修正：説明の簡略化・誘導の色分け・冠動脈名

- 常時表示の文章は短い凡例と心筋ハイライトの意味だけとし、長い説明と出典は閉じた「補足・参考資料」へ集約。
- 選択中は明るい青、鏡像側は橙色。誘導ボタンに加え、3D図の上部でも現在の選択と鏡像側を表示。
- 冠動脈ラベルを初期表示に変更。日本語名と略称を図の引き出し線へ直接表示し、別の血管名一覧は削除。
- 型チェックとビルド成功。PC幅のV2選択と390px幅のⅢ選択を操作し、両色の同期と日本語名の表示を確認。確認時のブラウザ警告・エラーなし。
- Sitesのビルド補助はWindowsのパスエラーで実行できなかったため、既存のpnpm buildで生成を確認。

## 意図の修正：心臓そのものの二色ハイライト

ユーザーの「心臓に色付けて」の指摘により、ボタン・図上バッジだけの色分けを修正。
- WebGL描画へ独立した第二の心筋表面領域を追加。選択側の表面は青、鏡像側は橙。同一場面で反対側の誘導を選ぶと、表面の色が入れ替わる。
- 下壁側と側壁側、後壁側と前胸部側を方向モデルとして示す。二つの梗塞領域・正確な灌流域・内部中隔の表示とは区別する。
- 通常の心臓色を控えめにし、冠動脈名を維持。「両側を見る」で二色を見比べる角度へ戻る。
- Ⅲで下壁側が青・側壁側が橙、V2とV7を切り替えて前胸部側と後壁側の色が反転することを実際の描画で確認。警告・エラーなし。68件のテスト、型チェック、ビルド成功。
