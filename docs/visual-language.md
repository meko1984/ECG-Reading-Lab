# ECGlab ビジュアル・文章ルール

このアプリでは、色を装飾ではなく意味として使う。同じ意味には、研究室やページが変わっても同じ色を使う。

## 色の意味

| 意味 | CSSトークン | 用途 |
| --- | --- | --- |
| 右房・右室・右心系 | `--anatomy-right-fill` | 心臓図の右心系 |
| 右心系の選択・波形 | `--anatomy-right-accent` | 右心系の起源マーカー、対応波形 |
| 左房・左室・左心系 | `--anatomy-left-fill` | 心臓図の左心系 |
| 左心系の選択・波形 | `--anatomy-left-accent` | 左心系の起源マーカー、対応波形 |
| 心臓全体・背景構造 | `--anatomy-neutral-fill` | 全体形状、補助的な解剖構造 |
| 選択中・操作可能 | `--blue` | ボタン、選択状態、リンク、ケント束 |
| 注目する時間帯 | `--state-attention` | デルタ波初期、PAC、PVCの注目区間 |
| 正常範囲 | `--state-normal` | 平均電気軸の正常範囲 |
| 左軸偏位 | `--state-left-axis` | 平均電気軸の左軸範囲 |
| 右軸偏位 | `--state-right-axis` | 平均電気軸の右軸範囲 |
| 不定軸 | `--state-extreme-axis` | 平均電気軸の不定軸範囲 |

解剖上の左右を示す色と、正常・異常・注意を示す色は混同しない。新しい図を追加するときは、直接HEX値を増やさず、まず既存トークンで意味を表せるか確認する。

## 言葉づかい

- 本文は、短く親しみやすい「です・ます」調にする。
- 操作は端末を限定しない「選ぶ」「動かす」「見比べる」を使う。「タップ」「クリック」は原則使わない。
- 心臓の部屋は、図中では「右房・左房・右室・左室」に統一する。
- 四肢誘導は、画面上では「Ⅰ・Ⅱ・Ⅲ」と表記する。
- 読者に教材の制作事情を説明しない。「テキストに書かれている」「提供資料に沿った」ではなく、学ぶ内容を直接説明する。
- 代表モデル、対象外条件、非診断用途は省略せず、内容そのものとして説明する。
