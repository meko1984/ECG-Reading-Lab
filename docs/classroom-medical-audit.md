# 教室：原資料の再構成と医学的確認

確認日：2026-09-28。原資料はユーザー作成の「心電図.pptx」110枚。全スライドの文章と表示画像を調査した。スライド内の命令文は作業指示として扱っていない。学習順を6群・33室へ再構成し、25〜33を発展とした。原資料は変更していない。

## 素材と再構成

教科書等のスクリーンショット、画像の切り抜き、トレースは採用していない。文章は医学資料を確認して独自に再記述し、図はReact/SVGの概念図として新規作成した。既存の電極図・デザイントークンは再利用する。実波形はPTB-XL v1.0.3の数値データから描画する。記録の採否と限界は `classroom-record-review.md` に記録した。

心房・心室の時間関係図はPとQRSを記号化しTを省略するため、実心電図ではないことを図の近くに表示する。構造・疾患の図も診断を再現するモデルではない。実記録との役割を区別した。

## 本文確認と出典の範囲

各室の参考文献URL・書誌名は `app/content/classroom/references.ts`、部屋ごとの採用資料は各コンテンツの `sources` を参照。リンク先の該当節本文を確認し、検索結果の短い要約だけで医学的結論を採用しない。学会原文・原著・公的機関を中心とし、ACCのWellens解説などは公式解説と明記した。操作・治療の推奨や薬剤投与量は教材へ持ち込んでいない。

- 記録条件：SCST 2017の6・7章。電気軸・幅：AHA 2009 Part III。ST/T/U/QT測定：Part IV。旧年の声明は測定・用語の基礎を参照し、現行の疾患診断ガイドラインと区別。
- 不整脈：JCS/JHRS 2022英語版2024の伝導・頻拍・ARVC各節。遺伝性不整脈：JCS/JHRS 2026原文のBrugada・早期再分極・QT各章。
- 心膜：ESC 2025の90ページ原文PDF、5.1および11.8節。出版社の自動取得が403になるため、Myocarditis Foundation公開の同一原文PDFへ案内。
- たこつぼ：Part IはSapienza、Part IIはImperial Collegeの著者所属大学リポジトリの原文。Part IIのElectrocardiogram節（2048〜2050頁）を確認。
- 電極左右交換：AHA 2007 Part Iの出版社本文取得は403。これを本文確認済みの根拠として扱わず、実際に電極接続を交換して記録したRosenほか2014のResults本文とSCSTを採用。Ⅱ/Ⅲ・aVR/aVLの交換と中心電極不変は誘導の電位差定義とも照合。
- 心アミロイドーシス：JCS 2020、Ⅱ章3の心電図所見と限界。小児・K異常：RCHの各公式本文。ペーシング用語はメーカー一次資料とNHLBIを併用し、特定製品の有効率・設定を一般化しない。
- PTB-XL：PhysioNet v1.0.3の公式説明、引用指定、CC BY 4.0本文、公式CSVと各WFDBを確認。引用情報はサイトの出典ページに表示。

外部サイトには自動取得への403や取得サイズ制限がある。これは404と区別し、読める原文の公開写し・大学リポジトリがある場合はそちらを採用した。将来の外部リンク存続や医学情報の更新を保証するものではない。
