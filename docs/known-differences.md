# iOS版との既知の差分

## Web版で修正した差分

### Ⅰ誘導プレビューのP波・T波

iOS 0.1.5の平均電気軸ラボでは、Ⅰ誘導プレビューがプリセット名 `Ⅰ誘導` を照合する一方、定義側は `Ⅰ` のため一致せず、P波とT波だけⅡ誘導の初期値へフォールバックする。

Web版ではⅠ誘導を選んだとき、Ⅰ誘導プリセットのP波・T波をそのまま使う。QRSは利用者が設定した値へ置き換える。この差分は意図した修正で、電気軸の計算式や判定境界は変更していない。

## 資料上の曖昧さへの対応

V5とV6の個別カード画像には重複が見られるため、Web版の波形値はスクリーンショットではなくSwiftソースのプリセットを基準にした。

## Web固有の差分

- iOSのネイティブ部品ではなく、ブラウザのスライダーとボタンを使う
- 横幅320〜520 CSS pxを主対象にした縦長レイアウト
- お問い合わせはXアカウントへの外部リンクで案内し、アプリ内の送信機能は実装しない
- 現段階では保存、共有、公開配信を実装しない

## Web版で追加した研究室

### WPW・ケント束ラボ

iOS 0.1.5には存在しないWeb版独自の学習ラボ。タイプA（僧帽弁輪側）・タイプC（中隔側）・タイプB（三尖弁輪側）の入門分類と、前方・中間・後方を組み合わせた9つの代表位置を扱う。

表示する波形は患者の実記録や診断用テンプレートではない。V1のA・C・B代表波形と、II・III・aVFのQRS開始後20 msのデルタ波極性を見分ける参考テキスト型の代表モデルである。

V1と下壁誘導の所見から弁輪上の候補へ、弁輪上の候補から代表所見へ双方向に同期する。精密なArruda法に必要なI誘導やIII・V1のR/S比は入力に使わず、同法の10領域判定とは明確に区別する。確定部位やアブレーション標的とは表示せず、クイズ、採点、潜在性・間欠性・多発副伝導路は扱わない。
