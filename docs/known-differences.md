# iOS版との既知の差分

## Web版で修正した差分

### Ⅰ誘導プレビューのP波・T波

iOS 0.1.5の平均電気軸ラボでは、Ⅰ誘導プレビューがプリセット名 `Ⅰ誘導` を照合する一方、定義側は `Ⅰ` のため一致せず、P波とT波だけⅡ誘導の初期値へフォールバックする。

Web版ではⅠ誘導を選んだとき、Ⅰ誘導プリセットのP波・T波をそのまま使う。QRSは利用者が設定した値へ置き換える。この差分は意図した修正で、電気軸の計算式や判定境界は変更していない。

## 資料上の曖昧さへの対応

V5とV6の個別カード画像には重複が見られるため、Web版の波形値はスクリーンショットではなくSwiftソースのプリセットを基準にした。

## Web固有の差分

- iOSのネイティブ部品ではなく、ブラウザのスライダーとボタンを使う
- 横幅320〜520 CSS pxを主対象にした縦長レイアウト
- お問い合わせはXアカウントへの外部リンクで案内し、アプリ内の送信機能は実装しない
- 現段階では保存、共有、公開配信を実装しない

## Web版で追加した研究室

### WPW・ケント束ラボ

iOS 0.1.5には存在しないWeb版独自の学習ラボ。提供されたテキスト画像を参考に、ケント束の付着部位をタイプA（僧帽弁輪）・タイプC（中隔）・タイプB（三尖弁輪）の3つへ整理した。

表示する波形は患者の実記録や診断用テンプレートではなく、V1のR＞S・QS型・rS型とデルタ波の最初の20 msを強調した代表モデルである。25 mm/s・10 mm/mVの方眼にPR 110 ms、QRS 160 msとして描く。

V1の3タイプ分類は入門用であり、B・Cと右側・中隔の対応には重なりがある。心臓図の位置は「代表位置」とし、V1単独で付着部位を確定できないことを明示する。クイズ、連続的な波形変形、細かなアブレーション部位の断定、潜在性・間欠性・多発副伝導路は扱わない。
