# 心臓３Dモデル — 実装・検証記録

## 採用した要求

2026-09-12のゴール設定と、その後の「外側のドームなどは対象外。あくまで心臓と誘導」を基準にした。

- ページタイトルは「心臓３Dモデル」、ルートは `/labs/lead-views`。
- 左右の心房・心室と冠動脈を備えた3D心臓模型。
- 12誘導のマーカーと心臓を一緒に回転。
- 誘導を選ぶと、その誘導の観察方向と代表領域をスポットライト風に表示。
- ドーム、台座、製品ロゴは含まない。

以前の会話内仕様から、タイトルと冠動脈の範囲は上記の最新要求へ更新した。波形・クイズ・疾患判定は本ページへ追加していない。

## 実装

- `app/domain/heart3d.ts`：患者基準の3次元座標、四腔をなめらかにつないだ心臓表面、主要な冠動脈と大血管の独自メッシュ、射影、誘導と領域のデータ、ラベル重なり回避。
- `app/components/heart3d-renderer.ts`：WebGLで立体形状を描画。深度判定、表面照明、代表領域の発光、半透明の観察コーン。
- `app/domain/heart3d-gesture.ts`：Pointer Eventsで共用する回転・ピンチ・タップの判別。キャンセルと拡大率の上下限を含む。
- `app/components/Heart3DLabClient.tsx`：3D表示、12誘導選択、視点ボタン、拡大縮小、説明、凡例。
- `app/labs/page.tsx`：研究室一覧に入口を追加。
- 新規外部依存、外部モデル、テクスチャ、保存・送信は追加していない。

右心系と左心系の色は既存の意味色を使用。冠動脈には金色のローカルトークンを追加した。模型は方向関係の学習用の模式形状で、患者画像から再構成したモデルではない。

冠動脈は左主幹部・LAD・対角枝・LCx・鈍縁枝・RCA・右縁枝・PDAを含む。PDAはRCAから分岐する代表例。心室表面へ冠動脈中心線を合わせている。

3D座標は患者の左を+X、頭側を+Y、前方を+Zとする。四肢誘導の正極方向はⅠ=0°、Ⅱ=60°、Ⅲ=120°、aVR=-150°、aVL=-30°、aVF=90°。これらは電極貼付位置ではない。V1〜V6は前胸部から左側へ連続し、V4〜V6の高さを揃える。

心臓、誘導アンカー、照明は同じ回転を使用する。画面上の文字ラベルだけは押しやすさのために重なりを避けて配置し、真の3Dアンカーまで細い線で結ぶ。裏側のマーカーは薄く破線表示する。視点操作は選択状態を維持し、「全体に戻す」だけが選択・回転・拡大を初期化する。

## 医学的な表示範囲

V1〜V2は中隔方向、V3〜V4は前壁〜心尖部方向、V5〜V6・Ⅰ・aVLは側壁側、Ⅱ・Ⅲ・aVFは下壁側の代表的な関連として表示する。内部の中隔を心外膜上の領域だと説明せず、V1・V2には内部方向であることを明示。aVRには特定の壁を一対一に割り当てない。

光は誘導の電気的測定範囲を物理的に再現したものではなく、代表領域を示す比喩。単一誘導からの局在・病気の確定や冠動脈支配域の判定には使わない。

参考として確認した資料：

- [Open RN / Nursing Advanced Skills, Chapter 7](https://www.ncbi.nlm.nih.gov/books/NBK594493/)：誘導群と心筋領域の基本的な関連。
- [Coronary Arteries: Normal Anatomy With Historical Notes and Embryology of Main Stems](https://pmc.ncbi.nlm.nih.gov/articles/PMC8200569/)：主幹・分枝と心臓表面の走行。
- [参考製品の発表](https://prtimes.jp/main/html/rd/p/000000016.000036950.html)：心臓と誘導の位置関係を立体模型として示す参考。写真や製品造形データは転載・使用していない。

## 公開経路の404修正

GitHub PagesのURLは独自ドメイン `https://ecg-reading-lab.mekomikudo.jp/` へ転送される。一方、従来のビルドはリンクとアセットに `/ECG-Reading-Lab` を付けていたため、トップから「研究室」などを選ぶと、独自ドメイン上の存在しない `/ECG-Reading-Lab/labs.html` へ移動して404になった。

公開ビルドを独自ドメインのルート用に変更する。リンクは `/labs.html`、`/labs/axis.html` などになり、各出力は `labs.html`、`labs/axis.html` に対応する。ローカル開発の `/labs` 形式と、必要な場合のリポジトリ配下プレビューも `createAppPath` のテストで維持する。

## 同日修正：マットな質感と誘導の混雑解消

ユーザーの追加要求「心房・心室のつながりをなめらかにしてマット寄りに」「誘導のマークを小さくするか競合をなくす」に対応した。

- 四腔の外形から滑らかな結合距離場を作り、Marching Tetrahedraで一続きの表面を生成。境目の形状・法線・右心系と左心系の色を補間。各部屋の配置と表記は維持。
- 鏡面反射を除去し、広い拡散光と控えめな陰影へ変更。観察用スポットライトは維持。
- 冠動脈を新しい心臓表面に沿わせ直した。
- 誘導の丸い表示は従来の46×44pxから直径34pxへ縮小。透明な押下領域は44×44pxを確保。
- 接続線・アンカーの主張を弱め、選択した誘導を強調。回転・拡大に応じた心臓と大血管の投影範囲を使ってラベルを避ける。操作説明の行にも重ならない配置に調整。
- 初回の3D準備中はマーカーを出さず、準備完了後に表示。サーバーとブラウザ間の微小な浮動小数点差による初期属性不一致も防止。
