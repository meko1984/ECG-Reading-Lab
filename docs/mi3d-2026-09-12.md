# 心筋梗塞ラボの3D表示

既存の心臓3Dラボの四腔・大血管・冠動脈メッシュと回転操作を共用。MIの6領域を選ぶと3Dの領域、血管の強調、視点と既存の波形・説明が連動する。元の2D模式図は折りたたみ内に残し、WebGL非対応時にも使用する。

- 領域の色は心筋表面上の滑らかな模式マスク。灌流域や梗塞範囲の厳密な再現ではない。
- 中隔のみ右側を切り開いた模式断面。心室内腔と細い中隔枝は描画しない。
- 右優位型の冠動脈走行を共用。下壁の代表血管はRCA/PDAを強調し、LCxが候補となる個人差を説明する。
- 血管ラベルは表面へ補正した座標を参照。中隔で切り取られる血管のラベルは出さない。奥側の表示は深度による簡略化。
- 参照した解剖資料：https://pmc.ncbi.nlm.nih.gov/articles/PMC4919754/ 、https://www.ncbi.nlm.nih.gov/books/NBK482375/

確認：型検査、変更ファイルのlint、既存のMI/3D/入力処理テスト。ブラウザで6領域の同期、390px幅の後壁、断面、回転によるyaw/pitch更新、縮小、警告・エラーなしを確認。実機スマートフォンの指操作は未実施。
