# 受け入れ確認項目

## ホーム

- タイトル、説明、3つの入口、学習用注意、version 0.1.5が表示される
- 3つの入口が各画面へ移動する

## 基本波形

- Ⅰ、Ⅱ、Ⅲ、aVR、aVL、aVF、V1〜V6が順番に表示される
- Ⅱ誘導にはP・Tラベルが表示される
- 320 px幅で横スクロールせず、波形がカード内に収まる

## 研究室

- 電極装着ミス、平均電気軸、WPW・ケント束を含む各ラボが操作可能である

## 電極装着ラボ

- RA、LA、RL、LL、V1〜V6の10電極と、人体上の正しい装着位置が表示される
- 電極を選んで人体上の位置を押すと装着でき、占有位置へ置くと2電極が交換される
- 「全部外して練習」と「正しく装着」で、未装着状態と基準状態を切り替えられる
- 1個でも未装着なら12誘導波形を描かず、各欄に「電極未接続」と表示する
- 正しい装着、RA–LA、RA–LL、LA–LL、V1–V2、V1・V2高位装着の代表状態を呼び出せる
- RA–LA交換ではIが反転し、IIとIII、aVRとaVLが交換され、aVFとV1〜V6は変わらない
- RA–LL交換ではIIが反転し、IとIIIが反転交換、aVRとaVFが交換される
- LA–LL交換ではIとII、aVLとaVFが交換され、IIIが反転する
- V1–V2交換ではV1とV2の波形が交換される
- V1・V2高位装着では、代表モデルとしてR波減高とP波変化が表示される
- 変化した誘導は枠と濃い波形で強調され、正しい装着時の波形が点線で重なる
- モデル外または未装着状態では、根拠のない波形を生成せず「モデル外」と表示する
- 患者の実記録ではないこと、実際は付け直して再記録すること、簡易モデルの対象外が表示される

## 平均電気軸ラボ

- 初期値はⅠ誘導 +5.7 mm、Ⅱ誘導 +7.0 mm、平均電気軸およそ +40.1°、正常範囲
- Ⅰ・Ⅱ誘導のタブを切り替えられる
- Q・R・Sをスライダーまたは±ボタンで0.1 mmずつ変更できる
- 波形、正味QRS、角度、分類、六軸図が即時更新される
- -30°と+90°は正常範囲に含まれる
- Ⅰ・Ⅱ誘導の正味QRSが両方0でも画面が壊れない
- Ⅰ誘導プレビューのP・TはⅠ誘導プリセットを使う

## WPW・ケント束ラボ

- V1のタイプA・C・B代表波形を選べる
- II・III・aVFの初期20 msデルタ波極性を＋・±・−から選べる
- V1を大きく、その横にV1選択肢、下段にII・III・aVFの波形と選択肢が表示される
- PCでは弁輪図と4誘導操作面が2列で同時に見える
- V1の大分類と下壁誘導の前方・中間・後方を組み合わせ、9代表位置のいずれかが推定候補として表示される
- 弁輪図が心室側から見上げた向きで、画面上を前壁、下を後壁として示す
- 三尖弁輪・僧帽弁輪・His束・冠静脈洞と、前中隔・中中隔・後中隔・左右自由壁の関係が読める
- 弁輪上の9領域をタップまたはキーボードで選ぶと、その領域の代表所見が4誘導へ反映される
- 心電図所見から弁輪図へ、弁輪図から心電図所見へ双方向に同期する
- V1の弁輪側と下壁誘導の前後方向が2段階で表示される
- A・B・Cと前方・中間・後方が詳細候補に併記される
- クイズや採点機能が表示されない
- 波形が患者の実記録ではなく模式波形であること、結果は確定診断でないことが表示される
- 4誘導モデルがArruda法の10領域判定ではないことが表示される
- 顕性・単一・順行伝導する副伝導路を前提とし、潜在性・間欠性・多発副伝導路は対象外と表示される
- 最終部位は電気生理学的マッピングとアブレーション成功部位で確認することが表示される

## ミラーイメージ・ST変化ラボ

- 15誘導の各ボタンを選ぶと選択表示と鏡像側の強調が同期する。
- Ⅱ・Ⅲ・aVFとⅠ・aVLは互いの誘導群を示し、左室下壁が強調される。
- V1〜V3とV7〜V9は互いの誘導群を示し、左室後壁が強調される。
- aVR・V4〜V6には固定の対応なしと表示し、心筋ハイライトを解除する。
- range入力、仮想視点、連続波形変形が存在しない。
- 四腔、冠動脈、大血管が実際に3D描画され、ドラッグ・視点ボタン・拡大縮小が動く。
- 心房・心室名、冠動脈名の切り替えと、前面・背面・下方の領域表示を確認する。
- PC幅と390px幅で選択と3D表示を確認し、横はみ出し・注釈の重なりを確認する。
- 鏡像変化は必発・完全反転ではなく、模型のみで病気を判定できないと示す。
- クイズ、採点、正解表示、診断判定がない。
