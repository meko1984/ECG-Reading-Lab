# 受け入れ確認項目

## ホーム

- タイトル、説明、3つの入口、学習用注意、version 0.1.5が表示される
- 3つの入口が各画面へ移動する

## 基本波形

- Ⅰ、Ⅱ、Ⅲ、aVR、aVL、aVF、V1〜V6が順番に表示される
- Ⅱ誘導にはP・Tラベルが表示される
- 320 px幅で横スクロールせず、波形がカード内に収まる

## 研究室

- 電極装着ミス、平均電気軸、WPW・ケント束を含む各ラボが操作可能である

## 電極装着ラボ

- RA、LA、RL、LL、V1〜V6の10電極と、人体上の正しい装着位置が表示される
- 電極を選んで人体上の位置を押すと装着でき、占有位置へ置くと2電極が交換される
- 「全部外して練習」と「正しく装着」で、未装着状態と基準状態を切り替えられる
- 1個でも未装着なら12誘導波形を描かず、各欄に「電極未接続」と表示する
- 正しい装着、RA–LA、RA–LL、LA–LL、V1–V2、V1・V2高位装着の代表状態を呼び出せる
- RA–LA交換ではIが反転し、IIとIII、aVRとaVLが交換され、aVFとV1〜V6は変わらない
- RA–LL交換ではIIが反転し、IとIIIが反転交換、aVRとaVFが交換される
- LA–LL交換ではIとII、aVLとaVFが交換され、IIIが反転する
- V1–V2交換ではV1とV2の波形が交換される
- V1・V2高位装着では、代表モデルとしてR波減高とP波変化が表示される
- 変化した誘導は枠と濃い波形で強調され、正しい装着時の波形が点線で重なる
- モデル外または未装着状態では、根拠のない波形を生成せず「モデル外」と表示する
- 患者の実記録ではないこと、実際は付け直して再記録すること、簡易モデルの対象外が表示される

## 平均電気軸ラボ

- 初期値はⅠ誘導 +5.7 mm、Ⅱ誘導 +7.0 mm、平均電気軸およそ +40.1°、正常範囲
- Ⅰ・Ⅱ誘導のタブを切り替えられる
- Q・R・Sをスライダーまたは±ボタンで0.1 mmずつ変更できる
- 波形、正味QRS、角度、分類、六軸図が即時更新される
- -30°と+90°は正常範囲に含まれる
- Ⅰ・Ⅱ誘導の正味QRSが両方0でも画面が壊れない
- Ⅰ誘導プレビューのP・TはⅠ誘導プリセットを使う

## WPW・ケント束ラボ

- タイプA・C・Bを切り替えられる
- 心臓図上のA・C・Bのケント束候補を直接タップまたはキーボードで選べる
- V1のR＞S・QS・rSの小波形を直接タップできる
- 心臓図とV1小波形のどちらから選んでも、模式断面・大きな波形・説明が同じタイプへ同期する
- 選んだタイプに応じて模式断面の代表位置が僧帽弁輪側・中隔・三尖弁輪側として強調される
- 模式断面がハート記号ではなく、左右非対称の外形、四腔、中隔、厚い左室壁、V1からの視点を表している
- タイプAのV1はR＞S、タイプCはQS型、タイプBはrS型の代表波形になっている
- デルタ波の最初の20 msが波形上で強調される
- 方眼上でP波開始からQRS開始までが110 ms、QRS幅が160 ms、初期20 msが半小マス相当になっている
- 付着部位とV1波形の理由を読み比べられる
- クイズや採点機能が表示されない
- B・Cは右側・中隔で重なるためV1だけでは確定できないことが表示される
- 波形が患者の実記録ではなく模式波形であること、細かな位置推定には12誘導全体や電気生理学的検査が必要なことが表示される
- 対象外の潜在性・間欠性・多発副伝導路について表示される

## ミラーイメージ・ST変化ラボ

- 下壁と後壁の2場面を切り替えられる
- 場面を切り替えると視点が直接側へ戻る
- 下壁ではⅡ・Ⅲ・aVF側のST上昇からⅠ・aVL側のST低下へ、視点スライダーに応じて波形が連続的に変わる
- 後壁ではV7〜V9側のST上昇からV1〜V3側のST低下へ、視点スライダーに応じて波形が連続的に変わる
- 中央ではSTが基線付近になり、実在の誘導ではない仮想視点だと表示される
- 下壁図で右房、右室、左室、心尖、下壁、大血管と患者の左右が読める
- 後壁図で胸の前後、胸骨、脊椎、両肺、右室、左室、後壁、前胸部・後壁誘導の位置が読める
- 初期状態へ戻すと下壁・直接側になる
- ミラーイメージが完全な上下反転ではなく、偏位量が一致しないことが表示される
- V1〜V3のST低下だけで後壁梗塞を確定できないことが表示される
- クイズ、採点、正解表示、診断判定がない
- 心臓図と波形が簡略化した独自ベクター模式図で、実患者の記録ではないことが表示される
