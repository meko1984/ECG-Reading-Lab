# ECG Reading Lab Web版 基本設計

## 1. 目的

スマートフォンで心電図の基本波形と平均電気軸の考え方を、図と操作で学ぶためのWebアプリ。判読や診断を代行せず、学習補助に限定する。

## 2. 対象と前提

- 主表示幅: 390 CSS px
- 対応下限: 320 CSS px
- コンテンツ上限: 原則520 CSS px。WPW操作面はPCで1120 CSS px
- タッチ操作を優先し、主要ボタンは原則44 px以上
- ローカルで動作するWebアプリとして実装し、この段階では公開しない

## 3. 画面構成

| パス | 画面 | 主な役割 |
| --- | --- | --- |
| `/` | ホーム | 波形・研究室・問い合わせへの入口、学習用の注意表示 |
| `/waveforms` | 基本波形 | 12誘導の代表波形を縦に比較 |
| `/labs` | 研究室 | 利用できる学習ラボと準備中テーマの一覧 |
| `/labs/electrodes` | 電極装着ラボ | 10電極の人体への装着、代表的な入れ替え・位置ミス、12誘導波形の比較 |
| `/labs/axis` | 平均電気軸ラボ | Ⅰ・Ⅱ誘導のQRS調整、波形プレビュー、六軸図、計算内訳 |
| `/labs/wpw` | WPW・ケント束局在ラボ | V1とII・III・aVFの代表波形、房室弁輪上の9代表位置を双方向に観察 |
| `/labs/mirror` | ミラーイメージ・ST変化ラボ | 下壁・後壁の代表場面で、直接側と反対側の誘導、ST上昇・低下を同時に観察 |
| `/contact` | 問い合わせ | XアカウントとDM受付の案内。アプリ内の入力・送信機能はなし |

## 4. 平均電気軸ラボ

### 入力

- Ⅰ誘導とⅡ誘導、それぞれのQ・R・S振幅
- 範囲: -20.0〜+20.0 mm
- 刻み: 0.1 mm
- スライダーと±ボタンを用意し、操作中に即時反映する

### 計算

1. 各誘導の正味QRSを `Q + R + S` で求める
2. `x = Ⅰ誘導の正味QRS`
3. `y = (Ⅱ誘導の正味QRS - 0.5 × x) / 0.8660254038`
4. `atan2(y, x)` を度数へ変換する

計算途中では丸めず、画面表示時だけ桁数を整える。

### 分類境界

- -30°以上 +90°以下: 正常範囲
- +90°より大きく +180°以下: 右軸偏位
- -90°以上 -30°未満: 左軸偏位
- それ以外: 不定軸 / 極度軸偏位

## 5. 波形描画

- Canvas 2Dで描画する
- 元資料の紙送り速度、ゲイン、P/QRS/Tの振幅・時間設定を使用する
- 画面幅と波高から方眼間隔を動的に決め、スマートフォンでも切れないようにする
- 12誘導のプリセット値はXcodeのSwift実装を基準とする

## 6. WPW・ケント束ラボ

- 顕性で順行伝導する副伝導路が1本あり、洞調律で前興奮が見える代表例を対象にする
- 参考テキストの学習順に合わせ、V1のA・C・B代表波形と、II・III・aVFの初期20 msデルタ波極性を組み合わせる
- 心室側から房室弁輪を見上げた模式図を使い、画面上を前壁、下を後壁として三尖弁輪・僧帽弁輪・His束・冠静脈洞の位置関係を示す
- 左前壁〜左前側壁、左側壁、左後壁〜左後側壁、前中隔、中中隔、後中隔、右前壁〜右前側壁、右側壁、右後壁〜右後側壁の9代表位置を扱う
- 下壁誘導のうち2誘導以上が陽性なら前方、2誘導以上が陰性なら後方、それ以外を中間とする方向学習モデルとして表示する
- 弁輪図と4誘導の操作面を同じカード内の2列に置き、場所と波形を一画面で見比べられるようにする
- V1を大きく表示し、その横にA・C・Bの代表波形選択、下段にII・III・aVFと各極性選択を並べる
- 波形側の所見変更と弁輪側の領域選択を双方向に同期し、2段階の見方を短く表示する
- 波形は患者の実記録ではなく、初期デルタ波極性を見分ける学習用模式波形とする
- より詳細なArruda法にはI誘導とIII・V1のR/S比も必要であり、この4誘導モデルはArruda法の10領域判定ではないと明示する
- 潜在性・間欠性・多発副伝導路、前興奮の程度や心臓位置による変化、最終アブレーション部位の断定は対象外とする
- クイズ・採点・連続補間は設けず、選択と判定経路の観察に集中する

## 7. 電極装着ラボ

- 12誘導を記録する10個の電極（RA、LA、RL、LL、V1〜V6）を、正面の人体模式図へタップで装着する
- 正しい装着を基準に、RA–LA、RA–LL、LA–LL、V1–V2の交換と、V1・V2の1肋間高位装着を比較する
- 四肢電極の交換は、I・II・III・aVR・aVL・aVFの定義に基づく入れ替えと極性反転として表現する
- V1・V2高位装着は、R波減高とP波変化を強調した代表モデルとし、患者ごとの変化量を再現するものではない
- 変化した誘導だけを強調し、正しい装着時の点線波形を重ねて差を読めるようにする
- 右足電極を含む交換、接触不良、ノイズ、複数の同時ミスはモデル外として波形を推測しない
- 10電極がそろわない状態では基準波形を代用せず、12誘導を「電極未接続」として描画しない
- 標準安静時12誘導として、四肢電極は肩・腰の体幹ではなく上肢・下肢の末梢寄りに示す
- 人体図と波形は独自模式図であり、患者記録や診断機能ではない

## 8. ミラーイメージ・ST変化ラボ

- 12標準誘導とV7〜V9から選択し、鏡像側の誘導群と左室下壁・後壁を強調する。
- 下壁：Ⅱ・Ⅲ・aVFとⅠ・aVL。後壁：V7〜V9とV1〜V3。両方向から選択できる。
- aVR・V4〜V6には固定の鏡像ペアを割り当てない。
- スライダー、仮想視点、波形補間を削除。誘導の選択と3Dの回転・拡大縮小で観察する。
- 四腔・大血管・主要冠動脈を備えたイラスト調の立体模型。右優位型の代表形状で、領域境界は模式的。
- ST低下の非特異性と、完全な波形反転・一対一の誘導ペアではないことを説明する。
- クイズ、採点、診断判定は設けない。

## 9. 安全性とデータ

- 医療判断には使えないことをホームとラボに明記する
- 入力内容はブラウザ内の一時状態だけで、保存・送信しない
- 問い合わせ画面にはXアカウントへの外部リンクを置くが、アプリ内の入力・送信機能は設けない
- XのDMでは、患者情報や個人を特定できる情報を送信しないよう明記する
- 分析、広告、アカウント、クラウド同期はこの版の対象外

## 10. アクセシビリティ

- 意味のある見出し順序とランドマークを使う
- Canvasと六軸図には内容を説明する代替テキストを付ける
- 誘導切替はタブとして公開し、左右キーでも切替可能にする
- キーボードフォーカスを視覚的に表示する
- `prefers-reduced-motion` を尊重する
