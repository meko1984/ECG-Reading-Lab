# ECG Reading Lab Web版 基本設計

## 1. 目的

スマートフォンで心電図の基本波形と平均電気軸の考え方を、図と操作で学ぶためのWebアプリ。判読や診断を代行せず、学習補助に限定する。

## 2. 対象と前提

- 主表示幅: 390 CSS px
- 対応下限: 320 CSS px
- コンテンツ上限: 520 CSS px
- タッチ操作を優先し、主要ボタンは原則44 px以上
- ローカルで動作するWebアプリとして実装し、この段階では公開しない

## 3. 画面構成

| パス | 画面 | 主な役割 |
| --- | --- | --- |
| `/` | ホーム | 波形・研究室・問い合わせへの入口、学習用の注意表示 |
| `/waveforms` | 基本波形 | 12誘導の代表波形を縦に比較 |
| `/labs` | 研究室 | 利用できる学習ラボと準備中テーマの一覧 |
| `/labs/axis` | 平均電気軸ラボ | Ⅰ・Ⅱ誘導のQRS調整、波形プレビュー、六軸図、計算内訳 |
| `/contact` | 問い合わせ | XアカウントとDM受付の案内。アプリ内の入力・送信機能はなし |

## 4. 平均電気軸ラボ

### 入力

- Ⅰ誘導とⅡ誘導、それぞれのQ・R・S振幅
- 範囲: -20.0〜+20.0 mm
- 刻み: 0.1 mm
- スライダーと±ボタンを用意し、操作中に即時反映する

### 計算

1. 各誘導の正味QRSを `Q + R + S` で求める
2. `x = Ⅰ誘導の正味QRS`
3. `y = (Ⅱ誘導の正味QRS - 0.5 × x) / 0.8660254038`
4. `atan2(y, x)` を度数へ変換する

計算途中では丸めず、画面表示時だけ桁数を整える。

### 分類境界

- -30°以上 +90°以下: 正常範囲
- +90°より大きく +180°以下: 右軸偏位
- -90°以上 -30°未満: 左軸偏位
- それ以外: 不定軸 / 極度軸偏位

## 5. 波形描画

- Canvas 2Dで描画する
- 元資料の紙送り速度、ゲイン、P/QRS/Tの振幅・時間設定を使用する
- 画面幅と波高から方眼間隔を動的に決め、スマートフォンでも切れないようにする
- 12誘導のプリセット値はXcodeのSwift実装を基準とする

## 6. 安全性とデータ

- 医療判断には使えないことをホームとラボに明記する
- 入力内容はブラウザ内の一時状態だけで、保存・送信しない
- 問い合わせ画面にはXアカウントへの外部リンクを置くが、アプリ内の入力・送信機能は設けない
- XのDMでは、患者情報や個人を特定できる情報を送信しないよう明記する
- 分析、広告、アカウント、クラウド同期はこの版の対象外

## 7. アクセシビリティ

- 意味のある見出し順序とランドマークを使う
- Canvasと六軸図には内容を説明する代替テキストを付ける
- 誘導切替はタブとして公開し、左右キーでも切替可能にする
- キーボードフォーカスを視覚的に表示する
- `prefers-reduced-motion` を尊重する

## 8. 技術構成

- React 19
- Next互換App Router（vinext）
- Vite / OpenAI Sites開発環境
- TypeScript
- 外部UIライブラリ、外部フォント、外部画像は使用しない
